# 心理学文献阅读回顾与自查

版本：v3.0.0。供学生在使用 AI 阅读心理学文献后，回顾自己的学习过程。

## ChatGPT：一句话读取 Skill

在原来的阅读对话末尾粘贴以下一句话；保留本次阅读的原文或相关段落供 AI 对照。

```text
请读取并按此 Skill 对本次文献阅读对话进行回顾、自查与能力训练判断（若无法完整读取，请明确说明）：https://raw.githubusercontent.com/dlwby1985/AI-Facilitated-Critical-Reading-Reflection/main/skills/psychology-reading-review/SKILL.md
```

- [查看 Skill](skills/psychology-reading-review/SKILL.md)
- [Skill 原始文本](https://raw.githubusercontent.com/dlwby1985/AI-Facilitated-Critical-Reading-Reflection/main/skills/psychology-reading-review/SKILL.md)
- [GitHub 文件页面](https://github.com/dlwby1985/AI-Facilitated-Critical-Reading-Reflection/blob/main/skills/psychology-reading-review/SKILL.md)

这是一条加载本次规则的请求，不是账号永久安装命令。AI 需要能实际读取公开链接；如果无法读取或只读到片段，请使用下方的完整 Prompt。新开一个没有阅读记录的聊天，不能假定 AI 已获得原来的交流。

## 其他 AI，或无法打开链接时：完整 Prompt

打开 [完整 Prompt v3](prompts/reading-review-v3.md)，复制全文，粘贴在原阅读对话末尾。

## 会获得什么

1. 有具体对话依据、不过度拔高的肯定。
2. 供自行思考的概念、理论与阅读目标自查；无需回复或提交答案。
3. 能力训练回顾：哪些具体表现有改善迹象、哪些实际练过、哪些尚未展开，以及可自行尝试的改进方向。材料不足与未展开分别说明。

反馈不计分，不把 AI 的解释当成学生已经掌握，也不替学生撰写独立疑问或个人反思。它不构成客观能力测量或教学效果证明。

仓库原有作业说明页面保留在 [index.html](index.html)。本次分发仅含可公开的文字规则，不含学生数据、论文 PDF 或聊天记录。
